# Последното течение

Кратка образователна игра за защита на морска костенурка от отпадъци. Създадена по [THE_LAST_CURRENT_CODEX_SPEC.md](THE_LAST_CURRENT_CODEX_SPEC.md): точно три вълни, три боса, три вида съоръжения и три глави от „Книга на проблемите“. Целият интерфейс е на български.

## Стартиране

Необходим е **Node.js 22.12+** (проверено с Node.js 24).

```bash
npm install
npm run dev
```

Отворете адреса, изписан от Vite. За продукционна компилация:

```bash
npm run build
npm run preview
```

`dist/` е готовият статичен сайт. Не отваряйте `index.html` директно чрез `file://`: използвайте HTTP сървър. Няма сървърна логика, профили, външни шрифтове, аналитични услуги или онлайн заявки по време на игра. Външните образователни източници се отварят само при натискане на връзка.

## Как се играе

1. Натиснете **Играй** и затворете кратките указания с **Разбрах**.
2. Изберете съоръжение и след това едно от шестте номерирани места. Може и в обратния ред.
3. Началните 110 еко кредита стигат за два събирача на отпадъци. Места **02 и 05** са подходящи за първи опит.
4. Натиснете **Начало на вълната**. Можете да строите, подобрявате и продавате по време на вълните. Кликването върху отпадъците не ги поврежда.
5. Изберете построено съоръжение, за да видите обхвата, подобрението и продажната цена.
6. **Пауза** и отварянето на книгата спират симулацията. Скриването на раздела автоматично включва пауза. `Esc` затваря свободните прозорци, отменя избора или включва/изключва паузата.
7. След загуба **Опитай вълната отново** възстановява здравето, кредитите и съоръженията от натискането на „Начало на вълната“.

Преградата забавя, събирачът чисти една цел, лодката чисти до три близки цели. Всяко съоръжение има точно едно подобрение. Продажбата връща 75% от вложеното, закръглено надолу.

## Структура и редактиране

| Файл / директория | Предназначение |
| --- | --- |
| `src/config/balance.js` | Здраве, цени, щети, обхват, забавяне, скорост, шестте места и маршрутът |
| `src/config/waves.js` | Предвидим график на появяване на отпадъците и босовете |
| `src/config/localeBg.js` | Българските текстове, точният финал, главите и имената на двамата автори |
| `src/config/chapters.js` | Образователни източници и илюстрации на главите |
| `src/game/systems/RunState.js` | Единен модел на играта; без зависимости от браузъра или Phaser |
| `src/game/systems/PathSystem.js` | Плавна пътека, измерена по дължина, вместо сравняване само по X |
| `src/game/systems/TowerSystem.js` | Избор на цели, площ на лодката и незастъпващо се забавяне |
| `src/game/scenes/GameScene.js` | Рисуване, обратна връзка и отделно състояние на финалната сцена |
| `src/ui/` и `src/style.css` | HTML меню, магазин, достъпни бутони, книга и адаптивно оформление |
| `src/storage/progress.js` | Защитено записване само на главите и настройката за звук |
| `public/assets/art/` | Оригинални SVG рисунки; редактират се с текстов или векторен редактор |
| `src/game/audio.js` | Кратки оригинални звуци, синтезирани с Web Audio |

**Преди представянето:** заменете двете стойности в `bg.creators` с реалните имена. Те са умишлено оставени като редактируеми заместители.

Phaser е фиксиран на **3.90.0**, Vite — на **7.2.2**, зависимостите имат `package-lock.json`. Играта използва Canvas renderer за надеждна работа без изискване за хардуерен WebGL. Симулацията е с фиксирана стъпка 1/60 s и ограничение на големите кадрови скокове до 100 ms. Няма отделни таймери за спаунване, които да останат активни след повторение.

## Проверки

```bash
npm test
npm run test:playthrough
npm run build
```

- `npm test`: логически проверки на икономика, насочване, забавяне, босове, повторение, пауза, край и устойчивост на локалното съхранение.
- `npm run test:playthrough`: целият игрови цикъл при 30 и 60 FPS с два обикновени събирача на места 02 и 05. Проверява и реалното задействане на мрежата и ускоряващата аура. Не прескача босове и не дава допълнителни кредити.
- GitHub Actions повтаря инсталирането чрез `npm ci`, проверките и компилацията. Работният процес **не публикува сайта**.

При автоматичния прогон вълните са **50,95 / 58,33 / 66,85 секунди**, а финалната сцена — **25 секунди**. Това са **3 минути 21 секунди** активна симулация, без времето за подготовка и четене. При обичайните 10–15 секунди за глава и кратка подготовка целта е около **4–5 минути**. Това е измерване на симулацията, а не потребителско проучване. Прегради и по-бавно четене могат да удължат времето.

Пълен успешен прогон в Chrome с обикновени контроли, четене и визуална проверка завърши за **4 минути 31 секунди**. За ръчна проверка на оформлението отворете `/tests/viewports.html` при работещ `npm run dev`; страницата превключва между 1366×768, 1920×1080 и 390×844. Тя не влиза в продукционния пакет.

Подробности за проведените проверки и ограниченията: [docs/QA.md](docs/QA.md).

## Статичен хостинг

Изпълнете `npm run build` и качете **съдържанието на `dist/`** в произволен статичен хостинг. `base: './'` позволява работа и в поддиректория, например GitHub Pages. Няма клиентски маршрути, затова директното отваряне и презареждане на началния адрес не изискват SPA rewrite правила.

За GitHub Pages използвайте deployment от `dist/` чрез избран от вас Pages workflow или отделен клон за публикуване. В това хранилище е включена само CI проверка. За локална демонстрация без интернет оставете `npm run preview` отворено; след като ресурсите се заредят, самата игра не изисква мрежа. Не е реализирана PWA инсталация или кеширане за ново отваряне напълно без сървър.

## Източници и лицензиране

Текстовете на трите глави са запазени дословно от спецификацията. Основните твърдения са проверени на 10 ноември 2026 г.:

- [UNEP: пластмасово замърсяване и морски отпадъци](https://www.unep.org/en/what-we-do/ocean-seas-and-coasts/ecosystem-degradation-pollution/plastic-pollution-marine-litter) — 19–23 милиона тона във водните екосистеми годишно.
- [FAO: изоставени и изгубени риболовни уреди](https://www.fao.org/responsible-fishing/marking-of-fishing-gear/abandoned--lost-or-otherwise-discarded-fishing-gear-%28aldfg%29/en) и [NOAA](https://www.noaa.gov/gc-international-section/marine-debris-derelict-fishing-gear) — продължаващ „призрачен улов“.
- [UNEP: Global Waste Management Outlook 2024](https://www.unep.org/en/publications/report/global-waste-management-outlook-2024) — прогноза за 3,8 милиарда тона битови отпадъци през 2050 г. Използван е актуалният адрес на доклада, а не старият IETC адрес.

Всички рисунки в `public/assets/art/` и синтезираните звуци са оригинални за проекта. Няма чужди снимки или аудиозаписи. Phaser, Vite и включените им зависимости запазват собствените си лицензи; те се намират в инсталираните пакети. Хранилището не задава нов общ лиценз върху работата на авторите.
